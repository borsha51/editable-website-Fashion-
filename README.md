# Nexora Web — Premium Fashion Store

Editable fashion storefront built for Render + Turso.

## Features
- Product catalog, category filtering, search
- Cart, wishlist, checkout/order request
- Turso-backed orders/newsletter
- Local browser AI fashion assistant via WebLLM; no paid AI API key
- Responsive premium editorial design
- SEO metadata, sitemap, robots

## Render
Build: npm install && npm run build
Start: npm start

Set TURSO_DATABASE_URL and TURSO_AUTH_TOKEN in Render.
